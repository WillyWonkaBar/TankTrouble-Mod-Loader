# What is this?
The goal of this extension is to be a suitable replacement for TamperMonkey (and by extension all of the other UserScript extensions) on TankTrouble, as due to recent changes to the way TankTrouble handles variables.

This extension Works on Chromium-based browsers and Firefox.

# Built-In mods
- Adds a join button to allow joining users dynamically.
- Disables shake globally.
